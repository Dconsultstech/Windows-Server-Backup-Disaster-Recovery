# Project Documentation

This directory contains the supporting documentation for the Windows
Server Backup & Disaster Recovery project.

## Documents

-   [Architecture](architecture.md) --- infrastructure, backup flow,
    permissions and recovery architecture.
-   [Disaster Recovery Runbook](disaster-recovery-runbook.md) ---
    structured recovery and post-recovery validation procedures.
-   [Restore Testing](restore-testing.md) --- backup verification,
    restore evidence and the SRV01 permission troubleshooting case.

## Documentation Principle

The documentation reflects the actual lab implementation and
distinguishes verified test results from procedures that are documented
for future controlled testing.
